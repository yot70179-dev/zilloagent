# TrendCart — חנות דרופשיפינג

חנות דרופשיפינג בעברית (RTL), רספונסיבית, ללא תלות בשרת — הכל קורה בדפדפן.

## מה יש כאן

```
store/
├── index.html    מבנה הדף: hero, קטלוג, למה-אנחנו, footer, מגירת עגלה, מודל תשלום
├── styles.css    עיצוב מלא (מצב כהה, רספונסיבי, אנימציות)
├── products.js   קטלוג המוצרים (נתונים בלבד — קל להחליף במקור אמיתי)
└── app.js        לוגיקה: פילטרים, עגלה ב-localStorage, תהליך הזמנה
```

## תכונות

- 🛍️ קטלוג מוצרים עם קטגוריות ופילטרים
- 🛒 עגלת קניות שנשמרת ב-`localStorage` (שורדת רענון)
- 🏷️ מחירים לפני/אחרי הנחה עם חישוב אחוז חיסכון
- 🚚 חישוב משלוח חינם אוטומטי (מעל ₪199)
- 💳 טופס הזמנה עם מסך אישור
- 📱 עיצוב רספונסיבי מלא לנייד

## הרצה מקומית

זה אתר סטטי — פשוט פותחים את `index.html`, או מריצים שרת קטן:

```bash
cd store
python3 -m http.server 8080
# ואז נכנסים ל- http://localhost:8080
```

## חיבור לספק דרופשיפינג אמיתי

1. **מוצרים** — להחליף את `window.PRODUCTS` ב-`products.js` בקריאה ל-API של הספק
   (AliExpress / CJdropshipping / Spocket) או למסד נתונים.
2. **הזמנות** — ב-`app.js`, בתוך ה-`submit` של `checkoutForm`, לשלוח את ההזמנה
   ל-backend שלכם (למשל ה-FastAPI שכבר קיים בפרויקט) שיבצע סליקה וימסור את
   ההזמנה לספק אוטומטית.
3. **סליקה** — לשלב ספק תשלומים (Stripe / PayPal / Tranzila / iCredit).

> זהו אתר הדגמה. אין בו סליקה אמיתית — טופס ההזמנה מדמה הצלחה בלבד.
